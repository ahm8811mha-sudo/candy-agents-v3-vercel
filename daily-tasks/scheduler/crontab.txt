# الجدولة على لينكس أو ماك.
#
# 1) عدل المسار أدناه ليطابق مكان المشروع عندك.
# 2) نفذ:  crontab -e   ثم الصق السطر الفعال.
# 3) تأكد:  crontab -l
#
# الحقول: دقيقة ساعة يوم شهر يوم-الأسبوع
# 0 15 * * *  =  الساعة 3:00 عصرا كل يوم.
#
# ملاحظة: cron يستخدم توقيت الجهاز. تأكد أن التوقيت مضبوط على الرياض:
#   timedatectl set-timezone Asia/Riyadh        (لينكس)
#   sudo systemsetup -settimezone Asia/Riyadh   (ماك)
#
# لتشغيله في أيام العمل فقط (الأحد إلى الخميس) استبدل * الأخيرة بـ 0-4

0 15 * * * cd /home/USER/daily-tasks && /usr/bin/node src/run.js >> logs/cron.log 2>&1
